# ika_gomulu — Gömülü Yazılım Modülü

LYDİA aracının düşük seviye donanım iletişim katmanı.

## Sorumluluk Alanı
- Arduino Mega 2560 ↔ Jetson Orin Nano seri köprüsü (USB, 115200 baud)
- VESC Flipsky 75100 motor sürücü haberleşmesi
- AS5600 enkoder verisi → /odom topic
- Servo kontrol komutlarının Arduino'ya iletilmesi

## Sorumlu Ekip
Gömülü-1, Gömülü-2
